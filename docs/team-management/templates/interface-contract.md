# 接口契约模板

> 起草方：后端开发工程师（提供方），前端开发工程师会签
> 依据：TEAM_MANAGEMENT.md §4 后端开发工程师（红线：不提供未评审契约、不擅自改库不通知）、§6 RACI 技术方案与接口契约、§10.3 无接口契约不联调
> 使用方：task-card（依赖与联调安排）、change-impact（契约变更影响面）、handover（契约作为交接物）
> 状态取值：草稿 / 待会签 / 已会签 / 已废止。**未会签的契约不得作为联调依据**（§10.3）。
